# CaddyCheck — Quick Start Guide

## Install

1. Download `CaddyCheck-1.0.1.apk` on your Android device.
2. Open the file and tap **Install**.
3. If Android asks about installing from an external source, allow it temporarily only if you trust the file.
4. Open CaddyCheck.

## First launch

1. Choose your language.
2. Review the onboarding screens.
3. Accept the privacy notice.
4. Tap **Start**.

## Add a product

1. Tap the add button on the home screen.
2. Allow camera access to scan a barcode, or use manual entry.
3. Enter the price and quantity.
4. Tap **Add to basket**.

If the product is not found, enter its name manually and continue.

## Set a budget

Tap the budget section on the home screen, enter an amount, and submit it from the keyboard. Leave the field empty to remove the budget.

## Share your basket

1. Open **Live sharing**.
2. Enter an optional name.
3. Start the session.
4. Copy the code or share it through WhatsApp.
5. The other person can open **Watch a basket** and enter the code.

Live sharing requires an internet connection for both people.

## Finish a trip

1. Open the comparison screen.
2. Enter the receipt total if you want to compare it.
3. Choose **Save trip**.
4. Select the store.

## Backup and restore

Open **Settings > Backup & restore**:

- Choose **Export data** to save a JSON backup.
- Choose **Import data** to restore a previous backup.

Keep the backup file private because it may contain your shopping history.
