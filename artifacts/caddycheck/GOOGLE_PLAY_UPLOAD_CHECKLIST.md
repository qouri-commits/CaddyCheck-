# CaddyCheck — Google Play upload checklist

## قبل إنشاء الإصدار

- [ ] نشر API الإنتاجي والتحقق من `/api/healthz`.
- [ ] تثبيت رابط API الإنتاجي داخل إعدادات البناء.
- [ ] بناء ملف Android App Bundle: `CaddyCheck-1.0.1.aab`.
- [ ] اختبار الحزمة على جهاز Android حقيقي.
- [ ] اختبار إذن الكاميرا ومسح الباركود.
- [ ] اختبار الإدخال اليدوي عند عدم توفر الكاميرا أو المنتج.
- [ ] اختبار إضافة المنتجات وتعديلها وحذفها.
- [ ] اختبار الميزانية والمجموع.
- [ ] اختبار المشاركة مع جهازين أو مثيلين.
- [ ] اختبار التذكير من الطرف الآخر وإنهائه من صاحب السلة.
- [ ] اختبار مقارنة الفاتورة وحفظ الرحلة.
- [ ] اختبار النسخ الاحتياطي والاستعادة.
- [ ] التأكد من أن النسخة هي `1.0.1` و`versionCode` هو `2`.

## إعداد التطبيق في Play Console

- [ ] إنشاء تطبيق جديد.
- [ ] الاسم: `CaddyCheck - حاسبة التسوق`
- [ ] اللغة الافتراضية: العربية أو الإنجليزية حسب الجمهور الأساسي.
- [ ] نوع التطبيق: Application.
- [ ] التصنيف: Shopping.
- [ ] الإعلان: No ads.
- [ ] رفع أيقونة التطبيق.
- [ ] رفع `feature-graphic-1024x500.png`.
- [ ] رفع 4–8 لقطات شاشة من `store-assets/`.
- [ ] لصق الوصف القصير.
- [ ] لصق الوصف الكامل.
- [ ] إضافة بريد دعم حقيقي.
- [ ] إضافة رابط سياسة الخصوصية العامة.
- [ ] إكمال App access.
- [ ] إكمال Ads.
- [ ] إكمال Content rating.
- [ ] إكمال Target audience.
- [ ] إكمال Data safety.

## الاختبار الداخلي

- [ ] إنشاء مسار Internal testing.
- [ ] رفع ملف `.aab`.
- [ ] إضافة حسابات المختبرين.
- [ ] تثبيت النسخة من رابط الاختبار.
- [ ] اختبار API والمشاركة من خارج شبكة التطوير.
- [ ] اختبار Android 10 أو أحدث إن أمكن.
- [ ] مراجعة Crash reports وAndroid vitals.
- [ ] رفع `versionCode` جديد في كل تحديث لاحق.
